# Jason Yuan Personal Website

Built with [SvelteKit](https://kit.svelte.dev/) and [TailwindCSS](https://tailwindcss.com/). Hosted statically with [GitHub Pages](https://pages.github.com/).

Standalone legal pages are available at `/privacy-policy/` and `/terms-of-service/`.
They are prerendered for direct access and are not linked from the homepage or shared navigation.
